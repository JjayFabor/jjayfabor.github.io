# 🖥️ Online Portfolio - React + Vite

This project is my **online portfolio**, built using **React** and **Vite** with minimal setup for fast development and deployment.

## ⚡ Tech Stack

- [React](https://react.dev/)
- [Vite](https://vitejs.dev/)
- [Tailwind CSS](https://tailwindcss.com/)
- [ShadCN/UI](https://ui.shadcn.dev/)
- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react) or [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) for Fast Refresh.

---

## 🚀 Workflow Reminder

After **every edit** to any file:

```bash
npm run build
npm run deploy
```

✅ This ensures the latest changes are properly built and deployed to update the live portfolio.
